## 🎯 Project Overview
**CartConnect** is a professional, conversion-focused landing page built for a Shopify App that recovers abandoned carts via WhatsApp. This project was engineered to showcase high-end UI/UX principles, including **responsive design, interactive content sections, and clean, modular code architecture.**

## 🚀 Key Features & UX Engineering
I focused on building a page that drives action:
*   **Conversion-Optimized Hero:** A clean, punchy header designed to grab the attention of Shopify store owners within seconds.
*   **Interactive Components:** Engineered custom tabbed content and FAQ accordions using vanilla JavaScript for zero-dependency performance.
*   **Responsive Grid System:** Utilized Bootstrap 5’s grid architecture for a pixel-perfect, mobile-first experience.
*   **Legal & Compliance Ready:** Includes a comprehensive Privacy Policy structure essential for Shopify App Store approval.
*   **Visual Engagement:** Integrated **Lottie Animations** to create a modern, high-quality feel that builds user trust.

## 🛠️ Technical Toolkit
*   **Layout Framework:** Bootstrap 5.3.0
*   **Frontend Logic:** Vanilla JavaScript (ES6+), DOM Manipulation
*   **Styling:** Custom CSS (Modular BEM-like naming convention)
*   **Visuals:** Lottie Player integration
